# Zoho Flow & AI Automation Engineering Portfolio

An interactive portfolio showcasing **6 production-grade AI + Zoho Flow automation architectures**, **Deluge Custom Functions (OAuth 2.0 `invokeurl`)**, **Webhook Trigger pipelines**, and a searchable directory of **1,000+ Zoho Flow connectors** and **20 built-in Zia AI Utilities**.

## Live Interactive Portfolio (`index.html`)
Open `index.html` in any browser (or deploy directly via **GitHub Pages**) to explore:
1. **6 Flagship AI Workflow Case Studies** (with interactive step-by-step node inspection & live JSON payload simulation):
   - **Case Study #1 (RevOps & CRM):** Autonomous Inbound Lead Qualification & Agentic Routing (`Zoho CRM` + `Zia Utilities` + `Deluge ICP Scoring` + `Zia Agentic Actions` + `Zoho Cliq`)
   - **Case Study #2 (Support & CX):** Sentiment-Driven Omnichannel Support Triage & Auto-Drafting (`Zoho Desk` + `Zia Tone & Summary` + `Anthropic Claude` + `Zia Agentic Actions`)
   - **Case Study #3 (RAG & Vector DB):** Enterprise RAG Knowledge Sync & LLM Evaluation Pipeline (`Zoho WorkDrive` + `DeepSeek` + `Weaviate` + `FlowiseAI` + `HumanLoop`)
   - **Case Study #4 (Voice AI & Ops):** Voice AI (`Vapi`) & Post-Meeting Action Dispatcher (`Webhook Trigger` + `Zia Punctuate, Summarize & Checklist` + `Zoho Projects`)
   - **Case Study #5 (E-Commerce):** AI E-Commerce Catalog Copywriter & Multilingual Localization (`Shopify` + `Zia Product Copy Utilities` + `OpenAI` + `Unbabel`)
   - **Case Study #6 (Finance):** Intelligent Overdue Invoice Recovery & Agentic Collections (`Zoho Books` + `Deluge Aging Function` + `Zia Generate Email` + `Zia Agentic Actions`)
2. **All Connectors & Zia AI Directory:** Filterable breakdown of Zoho Flow's native Zia AI actions, external LLMs, core logic blocks, Zoho suite apps, and third-party SaaS integrations.
3. **Deluge & Webhook Engineering Lab:** Copy-ready Deluge functions for OAuth API calls, cross-app date normalization, XML/JSON webhook parsing, and `FILE` binary handling.
4. **Zia Prompts & Interview Playbook:** Natural-language prompts for Zia Text-to-Flow and architecture Q&A.

## Quick Deploy to GitHub Pages
1. Push this repository to GitHub (`index.html` at the root).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch** → `main` / `/ (root)` and click **Save**.
